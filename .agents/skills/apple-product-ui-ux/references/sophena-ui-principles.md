# Principios de UI de Sophena

- Calma antes que estímulo.
- Whitespace antes que contenedores innecesarios.
- Tipografía antes que decoración.
- Una acción principal antes que cinco acciones iguales.
- Contexto antes que datos aislados.
- Insights antes que gráficas.
- Feedback antes que confirmaciones innecesarias.
- Progressive disclosure antes que formularios gigantes.
- Continuidad antes que castigo.
- Accesibilidad antes que efectos visuales.
- Consistencia antes que novedad.

El producto debe comunicar avance sin convertir los hábitos en una evaluación moral. Las tendencias y el contexto importan más que una racha aislada.
